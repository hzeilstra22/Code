## Dataset Source
The data used in this assignment came from Baseball Savant. 
I acquired the data utilizing the pybaseball python library that scrapes the website and exported a csv.

## Run instructions
library installation requirements: pandas, numpy, matplotlib, and seaborn

the dataset '2025_swings.csv' must be downloaded and stored in a folder named 'data' to be loaded and ran in the notebook 'python_refresher.ipynb'

There should also be an empty folder called 'images' where the plot images will be stored after running the notebook.
